Lunch Box

Search, sort, and review restaurants — an Android app built with Kotlin, Firebase Auth, and Cloud Firestore.

Download APK ↓ View source on GitHub →
These are real screenshots, not mockups — taken from the app actually installed and running on a real Android emulator (API 34), talking to a live Firebase project (Auth + Firestore) — the same backend the downloadable APK above uses. Building and running it end-to-end surfaced three real bugs (an invisible button, a double-counted rating, and case-sensitive search) — all fixed; details in the README.

Features

  • Email/password auth via Firebase Authentication
  • Restaurant list backed by Cloud Firestore
  • Live, case-insensitive search by name
  • Sort by rating, name, or location
  • Submit a star rating + written review; the restaurant's aggregate rating recomputes on submit

Stack

  • Kotlin, Android SDK (View system + ViewBinding)
  • Firebase Authentication, Cloud Firestore
  • Kotlin coroutines
  • MVVM — ViewModel + LiveData + repository layer
