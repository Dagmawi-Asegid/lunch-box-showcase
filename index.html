Lunch Box

Find real nearby restaurants on an interactive map, get directions, order (demo), and leave reviews — an Android app built with Kotlin, Firebase, and the free OpenStreetMap Overpass API.

Download APK ↓ View source on GitHub →
These are real screenshots, not mockups — taken from the app actually installed and running on a real Android emulator (API 34), talking to a live Firebase project and the live Overpass API — the same backends the downloadable APK above uses. Building and running it end-to-end surfaced five real bugs along the way (an invisible button, a double-counted rating, case-sensitive search, a rejected API request, and Firestore rules that were edited but never redeployed) — all fixed; details in the README.

Features

  • Email/password auth via Firebase Authentication
  • Real nearby restaurants via OpenStreetMap's free Overpass API — no billing or API key, unlike Google Places
  • Interactive embedded map with tappable pins
  • Directions — one tap opens Google Maps
  • Live search, sort by rating/distance/name/location, pull-to-refresh
  • Order (demo): real cart/checkout flow saved to your account — clearly labeled as a demo, no real payment or restaurant behind it
  • Submit a star rating + written review; the restaurant's aggregate rating recomputes on submit

Stack

  • Kotlin, Android SDK (View system + ViewBinding)
  • Firebase Authentication, Cloud Firestore
  • osmdroid (OpenStreetMap maps), OkHttp (Overpass API)
  • Google Play Services Location, Glide
  • Kotlin coroutines, MVVM — ViewModel + LiveData + repository layer
